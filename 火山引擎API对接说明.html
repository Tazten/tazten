一、什么是火山引擎豆包 API？

🎯 简单理解

火山引擎豆包 API 是一个"AI 视觉理解服务"，就像给电脑装了一双"智能眼睛"，可以看懂图片里的内容，并提取出关键信息。

在我们的产品中，豆包 API 负责"看懂"用户上传的账单图片，自动识别出金额、商户、时间、分类等信息。

💡 为什么选择火山引擎豆包？

  • 强大的视觉理解能力：可以准确识别图片中的文字和内容
  • 免费额度充足：每日提供 150万 token 免费额度，足够使用
  • 响应速度快：使用 Flash 模型，识别速度快
  • 易于对接：提供标准的 API 接口，方便集成

💡 关键理解：

豆包 API 就像产品的"大脑"，负责理解用户上传的图片。没有它，产品就无法自动识别账单内容，用户就需要手动输入所有信息。

三、如何对接火山引擎豆包 API？

第一步：注册和开通服务

用户视角：就像注册一个账号，获得使用 AI 服务的权限。

  • 访问火山引擎控制台（https://console.volcengine.com）
  • 注册/登录账号
  • 开通"豆包视觉理解"服务
  • 创建 API Key（就像获得一把"钥匙"，用来访问服务）

产品视角：这是对接的第一步，没有 API Key，产品就无法调用 AI 服务。

第二步：获取配置信息

用户视角：获取连接 AI 服务所需的信息。

  • API Key：用于身份验证（类似密码）
  • 模型端点（Endpoint）：指定使用哪个 AI 模型（我们使用 doubao-seed-1-6-flash）
  • API 地址：服务的位置（https://ark.cn-beijing.volces.com/api/v3）

产品视角：这些信息就像"地址"和"钥匙"，告诉产品去哪里找 AI 服务，以及如何证明身份。

第三步：配置环境变量

用户视角：把获取的信息"告诉"产品，让产品知道如何连接 AI 服务。

  • 在项目根目录创建 .env.local 文件
  • 填入 API Key 和模型端点
  • 保存文件（这些信息是保密的，不会公开）
# 火山引擎豆包 API 配置
ARK_API_KEY=你的API密钥
DOUBAO_MODEL_ENDPOINT=doubao-seed-1-6-flash

产品视角：环境变量就像产品的"配置文件"，告诉代码在哪里找到 API Key 和模型信息。

第四步：编写对接代码

用户视角：编写代码，让产品能够"打电话"给 AI 服务，发送图片，接收识别结果。

  • 创建 API 调用函数（在 lib/doubao/vision.ts 文件中）
  • 设置请求格式（告诉 AI 要识别什么，返回什么格式）
  • 处理响应数据（解析 AI 返回的结果）
  • 添加错误处理（如果 AI 服务出问题，给用户友好提示）

产品视角：这是对接的核心，代码负责：

  • 把图片地址发送给 AI
  • 告诉 AI 要识别哪些信息（金额、商户、分类等）
  • 接收 AI 返回的识别结果
  • 把结果转换成产品能用的格式

第五步：集成到产品流程

用户视角：把 AI 识别功能"嵌入"到产品的使用流程中。

  • 用户上传图片后，自动调用 AI 识别
  • 显示识别进度（让用户知道系统正在处理）
  • 识别完成后，自动保存结果
  • 如果识别失败，给用户友好提示

产品视角：AI 识别不是独立功能，而是产品流程中的一个环节，需要无缝集成。

第六步：测试和优化

用户视角：测试功能是否正常，优化识别效果。

  • 上传不同类型的账单图片测试
  • 检查识别准确度
  • 优化提示词（告诉 AI 如何更好地识别）
  • 优化响应速度

产品视角：确保 AI 识别功能稳定可靠，用户体验流畅。

📤 发送给 AI 的内容

当调用豆包 API 时，我们发送：

  • 图片地址：告诉 AI 要识别哪张图片
  • 识别要求：告诉 AI 要识别哪些信息（金额、商户、分类等）
  • 格式要求：告诉 AI 返回什么格式的数据（JSON）

📥 AI 返回的内容

豆包 API 识别后，返回：

  • 交易方向：支出还是收入
  • 金额：具体金额数字
  • 货币：人民币、美元等
  • 商户：店铺或平台名称
  • 分类：一级分类和二级分类
  • 时间：交易发生时间
  • 原始文本：图片中的所有文字
  • 置信度：AI 对识别结果的信心程度

五、对接的技术实现（简化说明）

🔧 API 调用方式

简单理解：就像给 AI 服务"打电话"，告诉它要做什么，然后等待回复。

  • 请求地址：https://ark.cn-beijing.volces.com/api/v3/responses
  • 请求方式：POST（发送数据）
  • 身份验证：在请求头中携带 API Key
  • 请求内容：图片地址 + 识别要求

📝 提示词设计（告诉 AI 如何识别）

我们通过"提示词"告诉 AI 要识别什么，以及如何识别：

  • 识别目标：账单图片中的关键信息
  • 返回格式：JSON 格式，包含哪些字段
  • 分类规则：支出和收入的具体分类选项
  • 特殊要求：商户必须是平台名，不能是个人名等

产品视角：提示词就像"说明书"，告诉 AI 如何工作。设计好的提示词能让 AI 识别更准确。

⚡ 性能优化

为了让用户体验更好，我们做了这些优化：

  • 选择快速模型：使用 Flash 模型，响应速度更快
  • 优化提示词：精简提示词，减少处理时间
  • 添加进度提示：告诉用户"AI 正在识别，请稍候"
  • 错误处理：如果识别失败，给用户友好提示
