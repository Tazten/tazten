📱 飞书通知卡片对接说明

—— 让每一次记账都有通知提醒

一、什么是飞书通知？为什么要用它？

💡 简单理解

飞书通知就像给你的记账系统装了一个"小助手"，每次有新的账单记录成功保存到数据库时，这个小助手就会自动给你发一条消息，告诉你："嘿，又有一笔新账单入库了！"

🎯 为什么要用？

想象一下，你正在开发一个记账系统：

  • 没有通知：你只能手动打开数据库或网页，才能知道有没有新记录
  • 有通知：每次入库，飞书自动弹出一条卡片消息，显示关键信息（金额、商户、分类等），一目了然

这样你就能实时了解系统的运行情况，不用一直盯着数据库看了！

二、对接流程（超简单 5 步）

1

创建飞书应用

访问 https://open.feishu.cn/，登录后点击"创建企业自建应用"，填写应用名称（如：记账通知助手）。

2

获取应用凭证

在应用管理页面，进入"凭证与基础信息"，复制 App ID 和 App Secret（这两个就像应用的"身份证"）。

3

配置权限

进入"权限管理"，开启 im:message（发送消息）权限，保存并提交审核（企业自建应用通常自动通过）。

4

获取接收者 ID

确定消息要发给谁：

  • 发给自己：需要获取你的 open_id（可以通过飞书开发者工具查询）
  • 发给群聊：在群设置中查看群 ID（chat_id）
5

配置环境变量

在项目的 .env.local 文件中添加：

FEISHU_APP_ID=你的AppID
FEISHU_APP_SECRET=你的AppSecret
FEISHU_RECEIVE_ID=你的接收者ID
FEISHU_RECEIVE_ID_TYPE=open_id

# 如果使用模板卡片（推荐）
FEISHU_USE_TEMPLATE=true
FEISHU_TEMPLATE_ID=你的模板ID
FEISHU_TEMPLATE_VERSION=1.0.0

三、数据流转：从入库到通知

完整流程：

用户上传账单 → AI 识别 → 数据验证 → 保存到数据库 → 自动发送飞书通知 → 你在飞书收到卡片消息

📋 通知卡片包含的信息

  • 方向：支出 / 收入（带图标）
  • 金额：交易金额和货币
  • 商户：商户名称
  • 分类：一级分类 / 二级分类
  • 时间：交易发生时间（标准格式）
  • 备注：账单备注信息
  • 置信度：AI 识别准确度
  • 颜色：支出=绿色，收入=红色（符合中国习惯）

四、使用模板卡片（推荐）

🎨 什么是模板卡片？

模板卡片就像是一个"消息模板"，你可以在飞书卡片搭建工具中设计好样式，然后在代码中只需要填入数据，就能生成统一、美观的卡片消息。

📝

创建模板步骤

1. 访问 https://open.feishu.cn/tool/cardbuilder

2. 点击"新建卡片"，设计你想要的样式

3. 使用变量占位符，如 ${amount}、${merchant}、${color} 等

4. 保存模板，获取 template_id 和版本号

5. 在环境变量中配置模板 ID

优势：样式统一、易于维护、可以在飞书 UI 中直接修改，无需改代码！

五、对接成果

✅ 实现效果

  • 每次数据入库成功，自动发送飞书卡片通知
  • 卡片显示完整的账单信息，一目了然
  • 颜色区分支出和收入，符合中国用户习惯
  • 通知失败不影响主流程，系统稳定可靠

核心价值：让记账系统"会说话"，实时反馈运行状态，提升开发和使用体验！
